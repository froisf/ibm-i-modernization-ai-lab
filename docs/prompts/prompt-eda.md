# Exemplo de Prompt: Arquitetura Orientada a Eventos (EDA)

Este é um exemplo de prompt utilizado no IBM Watsonx para estudar conceitos de arquitetura moderna aplicados ao contexto de sistemas legados.

## Prompt Utilizado

> "Explique o conceito de Arquitetura Orientada a Eventos (EDA) para um desenvolvedor RPG sênior, utilizando exemplos práticos de como o Apache Kafka pode ser integrado a um sistema IBM i para processamento de pedidos em tempo real."

## Objetivo

Entender como a arquitetura de eventos pode modernizar a comunicação entre sistemas legados e plataformas de e-commerce, garantindo escalabilidade e processamento assíncrono.
