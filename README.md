# 🤖 IBM Cloud AI Lab & IBM i Modernization

Bem-vindo ao meu laboratório de estudos em Inteligência Artificial e Cloud! 

Este repositório foi criado para documentar meus experimentos práticos com **IBM Cloud**, **Watsonx.ai**, **Machine Learning** e **Prompt Engineering**, aplicados ao contexto de modernização de sistemas legados (IBM i / AS400).

## 🎯 Objetivo

O objetivo deste projeto é explorar como as tecnologias modernas de IA podem ser integradas ao ecossistema IBM i para resolver problemas reais de negócios, especialmente nas áreas de Logística (WMS) e E-commerce.

## 🛠️ Tecnologias Utilizadas

*   **IBM Cloud** (Plano Lite para estudos)
*   **Watsonx.ai Studio** (Machine Learning e Foundation Models)
*   **Prompt Engineering**
*   **VS Code** (com extensão Code for IBM i)
*   **Git/GitHub**

## 📂 Estrutura do Repositório

*   `docs/` - Documentação detalhada e anotações de estudo.
*   `prompts/` - Exemplos de prompts criados para testes no Watsonx (em breve).
*   `assets/` - Imagens e capturas de tela dos laboratórios (em breve).

## 🚀 Como Este Projeto Pode Ajudar

Se você é um profissional de IBM i (AS400/RPG) buscando entender como a IA pode ser aplicada no seu dia a dia, ou se você é um entusiasta de IA querendo ver casos de uso práticos, sinta-se à vontade para explorar este repositório, clonar os exemplos e adaptar os prompts para a sua realidade.
